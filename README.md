# Carracho Server

Offizielle Downloads und Versionshinweise für **Carracho Server**. Die Server-GUI, der System-Daemon und die Linux-Builds werden im gemeinsamen [Carracho-Quellcodeprojekt](https://github.com/ProfDrLuigi/Carracho) entwickelt.

- **[Server-ZIP-Dateien](https://github.com/ProfDrLuigi/Carracho-Server/releases)** liegen ausschließlich bei den GitHub-Releases, nicht im Git-Verlauf.
- **[Server-Changelog](CHANGELOG.md)** enthält nur Server-Änderungen.
- Aktuelle Server-Version: **1.1.7 (Build 18)**.

Der Client hat [eigene Releases](https://github.com/ProfDrLuigi/Carracho/releases). Beide Programme bleiben im selben Xcode-Projekt und werden unabhängig veröffentlicht.
